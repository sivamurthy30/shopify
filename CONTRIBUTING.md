# 🤝 Contributing Guide

This project was built for the Xeno FDE Internship assignment, but I welcome feedback and suggestions!

## Development Setup

1. Fork the repository
2. Clone your fork
3. Follow SETUP.md instructions
4. Create a feature branch
5. Make your changes
6. Test thoroughly
7. Submit a pull request

## Code Style

- Use TypeScript for all new files
- Follow existing code patterns
- Add comments for complex logic
- Use meaningful variable names
- Keep functions small and focused

## Commit Messages

Format: `type: description`

Types:
- `feat`: New feature
- `fix`: Bug fix
- `docs`: Documentation
- `style`: Formatting
- `refactor`: Code restructuring
- `test`: Adding tests
- `chore`: Maintenance

Examples:
- `feat: add customer lifetime value prediction`
- `fix: resolve date range filter bug`
- `docs: update API documentation`

## Pull Request Process

1. Update README if needed
2. Add tests for new features
3. Ensure all tests pass
4. Update documentation
5. Request review

## Questions?

Feel free to open an issue or reach out directly!
